# Линейная алгебра — лабораторная работа 1

Jupyter-ноутбук с решением первой лабораторной работы по линейной алгебре
(осень 2025). Автор — Новоселова Владислава, БЭАД256.

## Содержание

1. **Библиотеки** — базовые операции с матрицами: нулевая и диагональная матрицы, след, обратная матрица, минор, `XᵀX`.
2. **Время** — собственная функция `my_det` (метод Гаусса с выбором ведущего элемента) и сравнение её скорости с `scipy.linalg.det`.
3. **Точность** — ошибки арифметики с плавающей точкой; матрица Паскаля и её определитель (теоретически равен 1, численно — нет).
4. **Матричные вычисления** — произведение и сумма квадратов диагональных элементов, сумма `λᵢ·aᵢ·bᵢᵀ`, диагональ произведения `AB`.
5. **Комплексные числа и геометрия** — поворот с растяжением, отражение и инверсия через комплексные числа; построение треугольника Серпинского и собственного фрактала.

## Как использовались библиотеки

### 🔢 NumPy: матрицы и операции над ними

| Задача | Что использовано |
|---|---|
| Создание матриц | `np.array`, `np.zeros`, `np.diag` |
| След, обратная матрица, определитель | `np.trace`, `np.linalg.inv`, `np.linalg.det` |
| Минор через срезы | `x[1:3, 0:2]` + `np.linalg.det` |
| Транспонирование и произведение | `np.transpose`, `np.dot` |
| Случайные матрицы и тесты | `np.random.randint`, `np.random.rand` |
| Метод Гаусса в `my_det` | выбор ведущего элемента через `np.argmax(np.abs(...))`, перестановка строк `A[[i, p]] = A[[p, i]]` |
| Матрица Паскаля | заполнение `np.zeros(..., dtype=int)` по правилу `P[i, j] = P[i-1, j] + P[i, j-1]` |
| Фракталы | пиксельная матрица `np.zeros((1000, 1000))`, случайный выбор преобразования `np.random.choice` |

### 🧮 SciPy: эталонный определитель

- `scipy.linalg.det` — проверка `my_det` на 50 случайных матрицах 50×50 (расхождение не больше `1e-6`).
- Сравнение скорости `sla.det` и `my_det` на матрицах 10, 100 и 1000 через `%timeit -o`.
- Определитель матрицы Паскаля 30×30 — пример того, как накапливается погрешность.

### 📈 matplotlib: графики и изображения

- Время работы двух функций определителя: обычный масштаб (`plt.plot`) и логарифмический (`plt.semilogy`).
- Фракталы, отрисованные как изображение через `plt.imshow` (палитры `gray` и `viridis`).

### ➗ math и комплексные числа

- Поворот задаётся числом `cos φ + i·sin φ` (`math.cos`, `math.sin`, `math.pi`).
- Все геометрические преобразования — через арифметику комплексных чисел Python (`1j`, `.real`, `.imag`, сопряжение).
